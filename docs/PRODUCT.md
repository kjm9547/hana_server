# Hana 제품 원칙

기능을 만들거나 바꿀 때의 판단 기준. 여기에 어긋나는 구현은 먼저 물어본다.

## 철학

**一期一会(이치고 이치에)** — 온라인이어도 한 번의 만남에 정성을 다한다.

## 원칙

- **대화는 누구나 무료로, 자유롭게.** 외모나 결제 여부로 대화 자체를 막지 않는다.
- **진지해질 때 유료.** 돈은 "진지함의 증명"에 받는다. 노출을 늘려주는 부스터(슈퍼라이크, 부스트 류)는 팔지 않는다.
- **유료 지점은 상태로 분리.** 가격 플랜은 아직 미정이다. 나중에 결제만 끼울 수 있게 "진지한 단계"는 별도 상태/플래그로 둔다.
- **국적은 자유, 한·일 매칭은 옵션.**

## 정성 장치 (후보, 미확정)

- 하루에 소개되는 사람 수 제한 (무한 스와이프 없음)
- 넘긴 사람은 다시 나오지 않음
- 첫 메시지는 최소 분량이 있는 편지
- 끝맺음 인사 (신고·차단은 별도로 항상 가능)

## 미결정

- "진지하게 넘어간다"를 앱 안에서 어떤 행동으로 정의할지
- 무료 대화에서 연락처를 교환해 앱 밖으로 나가는 문제
- 무료 대화의 스팸·불쾌 메시지 방어
